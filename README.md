# 🎧 Headphones Promotional Webpage

A responsive promotional webpage showcasing headphone products, special offers, and discounts. Designed with modern front‑end practices to highlight usability and clean UI.

---
![page-image](./web%20page.png)

## 🚀 Features
- Responsive layout for desktop and mobile
- Product listings with star ratings and prices
- Highlighted **HOT offers** section
- Special offers with countdown timers
- Clear call‑to‑action buttons ("Shop Now")

---

## 🛠️ Tech Stack
- HTML5
- CSS3 (Flexbox & Grid)
- JavaScript
